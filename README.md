# SwapSkill 2.0

Peer-to-peer student skill exchange platform built with React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features
- **Time-Banking Architecture**: Zero-cash, escrow-protected 1-credit exchange per 30-minute session.
- **3D Tilted Grid Hero**: 3D cylindrical carousel showcasing student skill disciplines.
- **Dynamic Floating Navbar**: Morphing glassmorphism sticky navigation.
- **Icy Blue & Deep Midnight Palette**: Clean, modern glassmorphic aesthetics.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + CSS Container Queries
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Smooth Scroll**: Lenis

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
